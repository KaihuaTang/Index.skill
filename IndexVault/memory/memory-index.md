# Memory Index (记忆索引)

> 知识库顶层索引。根据知识类型导航到对应子文件夹。
> 查询知识时，先通过此索引判断应进入哪个子文件夹，再通过子文件夹内的 `_local_index.md` 定位具体条目。

## 事实性记忆 (Factual Knowledge)

知道"是什么"：陈述性判断、定义、事实、公式、架构描述、基准测试结果、分类体系等。

→ [[事实性记忆/_local_index|查看索引]]

## 程序性记忆 (Procedural Knowledge)

知道"怎么做"：方法流程、算法步骤、代码实现模式、工具使用方法、部署流程等。

→ [[程序性记忆/_local_index|查看索引]]

## 条件性记忆 (Conditional Knowledge)

知道"何时、为何用哪种方法"：方法选择依据、性能权衡、适用场景、失败模式、对比分析等。

→ [[条件性记忆/_local_index|查看索引]]

## 元认知记忆 (Metacognitive Knowledge)

知道"我自己是怎么学、怎么错、怎么监控理解的"：学习策略、常见误区、心智模型、个人反思，以及其他无法归入前三类的知识。

→ [[元认知记忆/_local_index|查看索引]]
