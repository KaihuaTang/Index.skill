# Fast3Dcache: Training-free 3D Geometry Synthesis Acceleration

> [!abstract] TL;DR
> 2D/视频领域的 diffusion caching 加速方法直接搬到 3D 会导致严重的几何破坏（表面孔洞、拓扑错误）。Fast3Dcache 观察到 3D 去噪过程中体素占据场呈现**三阶段渐进稳定模式**，据此提出两个协同模块：PCSC 按体素稳定化趋势动态分配 cache 预算，SSC 按速度+加速度联合准则精确选择可缓存 token。在 TRELLIS 上实现 27% 加速、55% FLOPs 削减，几何质量几乎无损（CD 仅增 2.5%，F-Score 仅降 2%）。

## In My Own Words (用我自己的话)

2D 图像和视频的 diffusion 加速已经有很多 caching 方法了——核心思路都是"去噪步间存在冗余计算，cache 前一步的特征在下一步直接复用"。但这些方法搬到 3D 就炸了。为什么？因为 2D 里 cache 引入的小误差最多导致纹理模糊，但在 3D 体素表示里，微小的数值误差会在迭代中累积，直接导致拓扑断裂——表面出洞、非流形网格、几何扭曲。这不是"质量稍差"的问题，是"生成物理上不合法的 3D 模型"的问题。

Fast3Dcache 的关键洞察是：**3D 去噪过程中的体素占据场不是匀速变化的，而是呈现明确的三阶段模式**——先剧烈变化（粗糙形状形成）→ 中间阶段对数线性衰减（渐进稳定）→ 最终几乎不变（微调）。这意味着不同阶段应该给不同的 caching 预算。早期别 cache（变化太剧烈），中期按衰减趋势动态增加 cache 比例，后期可以大胆 cache。

具体怎么选哪些 token 可以 cache？论文同时看两个信号：速度（这个 token 的特征变化了多少）和加速度（这个变化速度本身稳不稳定）。两者联合打分，得分低的就是"稳定"的，可以安全 cache。同时每隔几步强制做一次全量计算来消除累积误差。

## Research Problem & Motivation (研究问题与动机)

- **问题**: 3D diffusion 模型推理成本极高（迭代去噪），但现有 caching 加速方法从 2D 直接迁移会破坏 3D 几何一致性
- **已有方案的不足**: DeepCache、TaoCache、FastCache 等均为 2D/视频设计，忽略了 3D 体素表示的拓扑敏感性；唯一的 3D 方法 Hash3D 不适用于 diffusion 框架
- **本文的切入角度**: 利用 3D 去噪过程中体素占据场的渐进稳定规律，设计几何感知的自适应 caching 策略

## Method (方法)

### Core Idea (核心思想)

观察到 3D 去噪过程中，"动态体素"数量（相邻步间占据状态改变的体素数）呈三阶段对数线性衰减模式。基于此，用 PCSC 预测每步的 cache 预算上限，用 SSC 在预算内精确挑选最稳定的 token 进行缓存。三阶段流程：Phase 1 全量计算（几何剧变期）→ Phase 2 动态缓存（渐进稳定期）→ Phase 3 激进缓存（微调期）。

### Key Innovations (关键创新)

1. **几何感知的 caching 动机** — 首次系统分析了为什么 2D caching 在 3D 失败（体素拓扑敏感性），并用体素占据场的三阶段稳定模式作为理论基础
2. **PCSC (Predictive Caching Scheduler Constraint)** — 用对数线性衰减模型预测每步可 cache 的 token 上限，将 caching 预算与几何稳定化趋势绑定
3. **SSC (Spatiotemporal Stability Criterion)** — 速度+加速度联合评分选择稳定 token；单独用速度反而效果差（F-Score 仅 44.96），加速度才是关键判据
4. **EAE (Error Accumulation Elimination)** — 周期性强制全量计算消除累积误差，简单但必要

### Key Formulas (关键公式)

**动态体素度量**（体素占据场变化量，XOR 计算）：

$$\Delta s_t = \sum_{i,j,k} \left( \mathcal{O}_{t+1}(i,j,k) \oplus \mathcal{O}_t(i,j,k) \right)$$

**PCSC 预测曲线**（对数线性衰减）：

$$\Delta\hat{s}_t = \sigma \cdot e^{\mu \cdot (t - \lceil T \cdot \rho_a \rceil)}$$

转化为 token cache 预算：$c_t = D^3 - \Delta\hat{s}_t / \gamma_{up}$

**SSC 缓存能力评分**（联合速度与加速度）：

$$C_i(t) = \omega \cdot \text{norm}(A_i(t)) + (1 - \omega) \cdot \text{norm}(V_i(t))$$

其中 $V_i(t) = \|v_i(t)\|_2$（速度幅值），$A_i(t) = \|v_i(t) - v_i(t-1)\|_2$（加速度幅值，即 Instantaneous Caching Error）。

## Results (结果)

### Main Results (主要结果)

**TRELLIS 框架 (Toys4K, 71 objects, 852 prompts)**:

| 方法 | 吞吐量 | FLOPs (T) | CD | F-Score |
|------|--------|-----------|------|---------|
| Vanilla | 0.5055 | 244.2 | 0.0686 | 54.82 |
| RAS (25%) | 0.6337 (+25%) | 125.1 (-49%) | 0.0867 (+26%) | 40.28 (-27%) |
| **Fast3Dcache (τ=8)** | **0.6426 (+27%)** | **110.3 (-55%)** | **0.0703 (+2.5%)** | **53.75 (-2.0%)** |

**与模态无关加速器的正交组合**：

| 方法 | 吞吐量 | CD | F-Score |
|------|--------|------|---------|
| Vanilla | 0.51 (1.0x) | 0.0686 | 54.82 |
| EasyCache | 1.95 (3.8x) | 0.0692 | 54.51 |
| **EasyCache + Fast3Dcache** | **5.27 (10.3x)** | **0.0694** | **54.77** |

### Key Findings (关键发现)

- RAS（直接移植的 2D caching）在 3D 上造成灾难性几何退化（F-Score 下降 27%），Fast3Dcache 仅降 2%
- 与 EasyCache 组合可达 **10.3x 加速**且质量几乎无损，证明 Fast3Dcache 提供正交收益
- 消融实验揭示：加速度 $A_i(t)$ 是 SSC 的核心判据（单独贡献 F-Score 53.54），速度 $V_i(t)$ 单独用反而比随机差（F-Score 44.96）
- PCSC 相比固定比例 caching 提升巨大（F-Score 54.09 vs 34.51），说明自适应预算分配是关键
- 超参 $\omega = 0.7$（加速度权重高于速度）和 $\mu = -0.07$（衰减斜率）效果最优

## Critical Analysis (批判性分析)

### Strengths (优势)

- **问题定义清晰且有洞察**：不是简单地"把 2D 方法改改用到 3D"，而是从体素占据场稳定化的物理现象出发，建立了几何感知的理论基础
- **Training-free**：不修改模型权重，即插即用，可叠加其他加速方法
- **消融设计好**：SSC 的速度/加速度单独 vs 联合对比，PCSC 固定 vs 自适应对比，都说明了设计选择的必要性
- **正交性验证**：与 TeaCache、EasyCache 的组合实验证明方法提供独立的加速维度

### Weaknesses (不足)

- **强绑定 TRELLIS 框架**：整个方法围绕稀疏体素表示设计，对隐式表示（如 CLAY、Hunyuan3D 的 SDF/NeRF 路线）不直接适用
- **加速幅度有限**：单独使用仅 27% 速度提升，与 2D 领域 2-3x 加速差距明显；真正有意义的 10x 加速依赖与 EasyCache 组合
- **仅评估几何阶段**：TRELLIS 是两阶段（几何+纹理），本文只加速第一阶段，纹理阶段的 caching 策略未讨论
- **对数线性衰减假设**：三阶段模式的普适性未在 TRELLIS 之外验证，更换 3D diffusion 架构后是否仍成立？
- **CLIP Score 下降明显**：Text-to-3D 实验中 CLIP Score 从 22.97 降到 19.77（τ=5），语义一致性损失较大

### What This Opens Up (开启的研究方向)

3D diffusion 的加速研究刚起步，本文建立了"几何感知 caching"的范式。后续可探索：(1) 将体素稳定化分析扩展到纹理阶段；(2) 针对隐式 3D 表示设计类似的稳定性准则；(3) 将 PCSC 的预测式调度与 learned step-skipping 结合。
