# Adapting Point Cloud Analysis via Multimodal Bayesian Distribution Learning

> [!abstract] TL;DR
> BayesMM 提出了一种 **无需训练的贝叶斯多模态分布学习框架**，用于点云的测试时自适应(TTA)。核心思想是将文本先验和流式视觉特征分别建模为高斯分布，通过贝叶斯模型平均自动调节两种模态的权重，取代了传统 cache 机制中启发式融合的不稳定做法。在多个点云基准上平均提升 4%+ 准确率，且几乎不增加推理开销。

## In My Own Words (用我自己的话)

现在的 3D 多模态模型（如 ULIP、Uni3D）通过对比学习把点云、图像、文本对齐到同一空间，零样本能力很强，但一到分布偏移的场景（噪声、遮挡、跨域）就掉点。现有的测试时自适应方法多数用一个固定大小的 cache 存最近的样本特征来在线修正预测，但 cache 容量有限导致信息不断丢失，而且 cache 分数和零样本分数的融合靠手调超参，很不稳定。

BayesMM 的做法是：**别存样本了，直接维护每个类的分布**。具体地，用 LLM 生成的多样化文本描述建立文本高斯先验（均值+协方差），然后随着测试样本流式到来，在线更新每个类的视觉高斯分布（贝叶斯递推更新均值和协方差）。最后用贝叶斯模型平均把两个模态的后验预测加权融合——权重不是手调的，而是由各自的后验证据自动决定的。整个过程不需要任何训练，就是纯概率推断。

这个思路的优雅之处在于：用分布替代 cache 天然解决了信息丢失问题（分布是对历史的充分统计量），贝叶斯融合天然解决了超参调节问题。实验上在 4 个主流 3D backbone 上都一致有效，而且内存和速度开销几乎可忽略。

## Research Problem & Motivation (研究问题与动机)

- **问题**: 多模态 3D 视觉-语言模型在分布偏移下性能显著下降，需要在测试时进行无训练的在线自适应
- **已有方案的不足**: Cache-based TTA 方法有两个结构性缺陷——(1) 固定容量 cache 导致渐进信息丢失；(2) cache logits 与 zero-shot logits 的融合依赖启发式超参 $\lambda, \gamma$，跨域不稳定
- **本文的切入角度**: 将 TTA 重新形式化为**动态多模态分布学习问题**——用高斯分布替代 cache 存储，用贝叶斯推断替代启发式融合

## Method (方法)

### Core Idea (核心思想)

不存样本，存分布。将每个类的文本和视觉特征分别建模为高斯分布，文本分布从 LLM 扩写的多样化 prompt 中估计（静态先验），视觉分布随测试流在线贝叶斯更新（动态后验）。两个模态通过贝叶斯模型平均自动加权融合，权重由后验证据量决定——哪个模态对当前样本更"确信"，就给更大权重。

### Architecture (架构)

![[2026-04-06_paper_001_05.png|600]]

输入：流式点云 $\{X_t\}$ + 固定文本原型 $\{T_c\}_{c=1}^C$（如 "a 3D object of [classname]"）

冻结编码器：点云编码器 $\Phi$ 和文本编码器 $\Psi$ 将输入投影到共享特征空间 $\mathbb{R}^d$

三阶段流程：
1. **文本分布学习**：LLM 扩写 prompt → 编码 → 估计每类的文本高斯 $\mathcal{N}(\bar{z}^c, S^c)$ → MAP 求解文本原型
2. **视觉分布学习**：以文本分布为初始先验 → 每来一个测试样本执行一次贝叶斯递推更新均值和协方差
3. **贝叶斯融合**：两个模态的类后验通过后验证据加权求和，输出最终预测

### Key Innovations (关键创新)

1. **分布替代 Cache** — 高斯分布的均值和协方差是对历史样本的充分统计量，理论上零信息损失，且内存恒定不随样本数增长
2. **贝叶斯递推更新** — 视觉分布的在线更新有闭式解（高斯-高斯共轭），无需梯度下降或任何训练
3. **自动模态权重** — 贝叶斯模型平均根据后验证据自适应调节文本/视觉的贡献，消除手调超参需求

### Key Formulas (关键公式)

**视觉分布的贝叶斯递推更新**（核心公式）：

$$\mu_t^c = \Sigma_t^c \left( (S^c)^{-1} x_t + (\Sigma_{t-1}^c)^{-1} \mu_{t-1}^c \right)$$

$$\Sigma_t^c = \left( (\Sigma_{t-1}^c)^{-1} + (S^c)^{-1} \right)^{-1}$$

**贝叶斯多模态融合**：

$$p(c \mid x_t) = p(c \mid x_t, \Omega^c) \cdot p(\Omega^c \mid x_t) + p(c \mid x_t, \Theta_t^c) \cdot p(\Theta_t^c \mid x_t)$$

其中 $p(\Omega^c \mid x_t)$ 和 $p(\Theta_t^c \mid x_t)$ 分别为文本和视觉模态的后验权重，自动由数据决定。

### Key Findings (关键发现)

- BayesMM 在 4 个主流 3D backbone (ULIP, ULIP-2, OpenShape, Uni3D) 上**一致有效**，平均提升 4%+
- 在弱 backbone (ULIP) 上提升最大 (+10.8%)，说明方法对基础能力较弱的模型补偿作用更强
- 消融实验显示文本分布贡献 > 视觉分布贡献，文本模态在分布偏移下更稳定
- 超参 $\alpha^2, \beta^2$ 对性能几乎无影响，证实了方法的鲁棒性
- 内存仅增加 ~4MB（从 40 类扩展到 1156 类），速度保持零样本推理的 97%+

## Critical Analysis (批判性分析)

### Strengths (优势)

- **理论优雅**：把 TTA 形式化为贝叶斯推断问题，所有组件（分布估计、在线更新、模态融合）都有概率论基础，不是工程拼凑
- **真正的 Training-free**：无需反向传播、无需额外数据、无需超参搜索，即插即用
- **可扩展性好**：内存和计算开销几乎恒定，不随类数或样本数增长——这在大规模开放词汇场景 (O-LVIS, 1156 类) 中很关键
- **消融充分**：组件消融 + 超参敏感性 + 模态权重分析 + 可视化，实验设计严谨

### Weaknesses (不足)

- **高斯假设的局限性**：特征空间中每个类真的是单峰高斯吗？对于形态多样的类（如 "furniture"）可能存在多模态分布，单高斯无法捕获
- **O-LVIS 上 Uni3D 掉点**：Uni3D+BayesMM 在 O-LVIS 上从 55.42 降到 53.63，说明在极大类数场景下方法可能引入类间混淆
- **缺少与非 cache 方法的对比**：如 entropy minimization、prompt tuning 等 TTA 方法未纳入比较
- **文本扩写依赖 LLM 质量**：prompt 多样性和质量直接影响文本先验，但未讨论不同 LLM 的影响

### What This Opens Up (开启的研究方向)

高斯分布是最简单的参数化选择。自然的延伸方向包括：(1) 混合高斯建模多模态类分布；(2) 将框架扩展到 2D vision-language 模型（如 CLIP）的 TTA；(3) 探索非平稳环境下的遗忘-适应权衡（引入时间衰减因子）。
